# Youssef Noaman — Portfolio

A personal portfolio built with React to introduce my skills and showcase my projects.

## Overview

The site includes an introduction, skills, projects, and contact sections. It was built with Create React App and uses Bootstrap and animation libraries for the interface.

## Built with

- React and Create React App
- React Bootstrap and Bootstrap
- React Router
- Animate.css and WOW.js
- Font Awesome and React Bootstrap Icons

## Run locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/YoussefNoaman96/YoussefNoaman-portfolio.git
cd YoussefNoaman-portfolio
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

## Available commands

- `npm start` — start the development server.
- `npm test` — run the test runner.
- `npm run build` — create a production build in the `build` folder.
